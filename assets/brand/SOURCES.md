# MKL identity

The official MKL vector mark is copied from the portfolio's
`public/brand/mkl-monogram.svg` (source blob
`50e6d6b39650bb1ff16a176c9f9c6feb65e4ecb5`). Its coordinate precision is reduced
to two decimals; the paths and viewBox proportions are preserved. The header
generator inlines these paths in ivory on obsidian. No replacement mark was drawn.

Brand reference: https://mubashir-portfolio-orpin.vercel.app

Palette: obsidian `#0a0a0a`, warm ivory `#fcfaf5`; restrained cyan and violet
accents. The portfolio uses EB Garamond, Alata and Source Code Pro. GitHub SVG
assets use Georgia, system sans-serif and Consolas fallbacks to avoid remote
font dependencies. Opaque dark surfaces are intentional in both GitHub themes.
