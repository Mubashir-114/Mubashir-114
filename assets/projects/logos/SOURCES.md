# Project logo sources

These are optimized, aspect-ratio-preserving copies of artwork already committed
to each featured public repository. No logo was recolored or redrawn.

| Local file | Repository source |
| --- | --- |
| `kodehax.png` | [`static/image/logo2.png`](https://github.com/Mubashir-114/kodehax_academy/blob/main/static/image/logo2.png) |
| `provia.png` | [`static/images/branding/provia-logo.png`](https://github.com/Mubashir-114/Provia/blob/main/static/images/branding/provia-logo.png) |
| `fintrack.png` | [`Icon-App-1024x1024@1x.png`](https://github.com/Mubashir-114/budgetbee-app/blob/main/ios/Runner/Assets.xcassets/AppIcon.appiconset/Icon-App-1024x1024%401x.png) |
| `nexo.svg` | [`src/assets/nexo-mark.svg`](https://github.com/Mubashir-114/Nexo-frontend/blob/main/src/assets/nexo-mark.svg) |

The card accents follow each asset's visible palette. Raster colors were sampled
from the optimized local copies: Kodehax `#ffffff` / `#000000`, Provia
`#fac432` / `#9d9d9d`, and FinTrack `#38a5f7` / `#fbc723`. Nexo uses
`#3b82f6` / `#a855f7` directly from the source SVG gradients.
