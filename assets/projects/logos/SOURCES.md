# Project logo sources

The active cards use project-owned artwork with original colors and proportions.
FinTrack and kodehax use authentic colored variants identified in their source
repositories; no generated substitute or recoloring was used.

| Active local file | Repository source |
| --- | --- |
| `fintrack-jade.png` | [`assets/branding/logo_obsidian_jade.png`](https://github.com/Mubashir-114/fintrack_app/blob/main/assets/branding/logo_obsidian_jade.png), source blob `3da4d72ab746a9aaff97cdec1d973216bffabdc6`, optimized to 192 × 192 pixels |
| `kodehax-color.png` | [`static/image/image.png`](https://github.com/Mubashir-114/kodehax_academy/blob/main/static/image/image.png), source blob `4e792a4cac2e0d7c23152e741c71e6c69d6cb8ea`, optimized proportionally to 189 × 192 pixels |
| `provia.png` | [`static/images/branding/provia-logo.png`](https://github.com/Mubashir-114/Provia/blob/main/static/images/branding/provia-logo.png), existing optimized artwork preserved |
| `nexo.svg` | [`src/assets/nexo-mark.svg`](https://github.com/Mubashir-114/Nexo-frontend/blob/main/src/assets/nexo-mark.svg), existing vector artwork preserved |

Card accents follow each project's character: jade green; blue/violet;
gold/yellow; blue/purple. Surface tints and decorative edge gradients are UI
treatments, not modifications to the project logos.
